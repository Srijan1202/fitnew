# Beta 5.3 plan — Cobalt everywhere, and a new admin site

**Status:** waiting for the owner's "go". No code before it.
**Date:** 2026-11-01
**Owner, 2026-11-01:** "changing the default ui dark to cobalt … make a light mode also on similar theme and also make the app logo on similar theme, also make the appearance collapsable in profile and it should be collapsed by default, also match the website and admin website on same theme … overhaul the admin website ui … change complete ui ux of admin ui page make it more modern and easy to use".

**Owner's answers:**
- Automatic follows the phone: Cobalt in dark mode, the new Cobalt Light in light mode.
- Everyone is moved once to the new default.
- The cobalt logo is the default; the lime icon stays a choice in the app.

The version is assumed to be **5.3 (build 33)**; say if it should be something else.

## 1. App themes

| # | Change |
|---|---|
| T1 | **Cobalt Light**, a new free theme: a cool near-white paper (`#F6F8FC`), white cards, deep navy ink (`#0B1220`), slate greys, and the same cobalt actions (`#2E6BF0`, white text) with a soft blue glow. Green, amber and red keep their meanings, darkened for contrast on light. |
| T2 | **Automatic = Cobalt / Cobalt Light.** With no theme chosen, the phone's dark mode shows Cobalt and its light mode shows Cobalt Light. It still follows a switch of the phone while FITOS is open. |
| T3 | **The picker order:** Automatic, Cobalt, Cobalt Light, Dark, Light, then the green FITOS themes, then premium and reward themes. Dark and Light stay as choices. |
| T3a | **Two premium themes** (owner, 2026-11-01: "a purple and black and purple and white theme … as a paid theme"): <br>• **Violet:** true black, violet actions (`#7C3AED`, white text, 5.7:1), a lighter violet glow (`#8B5CF6`), violet-tinted greys; <br>• **Violet Light:** a soft near-white paper (`#FAF8FF`), white cards, deep plum ink (`#170F26`), violet actions (`#7C3AED`, white text). <br>They are premium like Night, Forest, Ocean and Ember: locked with the premium mark for free users, and losing premium goes back to Automatic. Both get goldens and the same AA contrast check. |
| T4 | **Everyone moved once** (owner): the saved theme moves to a new key (`theme.v3`), so every phone opens on Automatic (Cobalt / Cobalt Light) after the update. People can choose again in Profile. |
| T5 | **Profile → Appearance collapses** and is collapsed by default. The closed row shows the current theme and icon ("Automatic · Cobalt icon"); a tap opens the theme and icon pickers. It opens closed every time Profile opens. |
| T6 | **Checked:** every screen's golden is generated again in Cobalt and Cobalt Light, and the contrast of text and actions is tested against WCAG AA (4.5:1 for text) in both. |

## 4. Admin site: a new design

The admin site is rebuilt on the same Cobalt tokens, dark and light following the computer, with a switch in the top bar to pin one.

| # | Change |
|---|---|
| A1 | **Layout:** <br>• a slim left sidebar with an icon and a name for each page, in the four groups, with a count badge where there is work waiting (feedback, corrections, demos, missing foods); <br>• a top bar with the page title, a search box, the mode switch and the signed-in admin; <br>• on a phone, the sidebar becomes a drawer and the tables become cards, as now. |
| A2 | **Search everything (Ctrl+K):** one box finds a page, a person (by email), a food or an exercise, and jumps to it. |
| A3 | **Overview becomes a dashboard:** <br>• cards for the numbers that matter (people, active this week, premium, waiting work); <br>• each card links to its page; <br>• the provider health and the acceptance rates sit below, in charts instead of tables. |
| A4 | **Tables:** <br>• a search and filters at the top of every list; <br>• sortable columns; <br>• sticky headers; <br>• paging that remembers where you were; <br>• empty and loading states that say what to do. |
| A5 | **Edit without leaving the list:** a row opens a side panel (a food, an exercise, a person, a feedback thread) instead of a new page. Save and close return to the same place in the list. |
| A6 | **Clearer actions:** <br>• one primary button per screen; <br>• destructive actions in red, with an undo toast instead of a browser confirm where the API allows it; <br>• every save says so in a toast. |
| A7 | **Exercise demos** keep Approve, Reject with a note, and Copy all notes. The animations get a larger view on click, and arrow keys move to the next demo. |
| A8 | **No change to what the admin can do:** the same pages, the same API, the same audit. This is a redesign of how it looks and works, not of its powers. |
| A9 | **Checked:** <br>• ci-admin type-checks, lints and builds; <br>• every page is opened in both modes, at desktop and phone width, before release; <br>• screenshots go to the owner for review. |
